# No.03《庞贝》Pompeii · 24 Aug 79

从广场上朱庇特神庙的废墟望出去，维苏威就在神庙背后——今天站在同一个位置也能看见它。那天下午，小普林尼在海湾对岸看见火山上升起一朵「像伞松」的云：一根柱子冲上天，顶上摊开，盖住整片天空。云里打着黄色的闪电，火山口和往下淌的熔流是全画唯一的橙；浮石灰像雨一样斜着落下来，广场上的小人往外逃，前景是倒下的柱段。

![No.03 庞贝](../../examples/03_pompeii_s1.png)

## 配色
15 生态退化（底 `#1E1B17`，由 `#51483E` 压深）
- `#657E8C` 污染蓝：夜空、石头顶上的冷边
- `#8F9B78` 退化灰绿：伞松灰云、落下的浮石灰
- `#D4C56C` 枯萎黄：闪电、朝火山一侧被火照亮的柱边、逃跑的人
- `#C77D53` 氧化橙：火山口与熔流（唯一焦点）
- `#51483E` 腐殖深褐：火山的顺坡刻线、广场地面

## 刻法
和 No.01、No.02 同一套：背景刻线（夜空横向断线、灰云 curl 流线只走在云的形状里、地面横线和透视缝）→ 剪影整块盖掉 → `rim()` 只在受光的边上刻断续亮边（朝火的一侧黄，顶面蓝）。远处的火山不做死黑剪影，用深褐顺坡线排出来，好让神庙的剪影压在它前面读得出。
