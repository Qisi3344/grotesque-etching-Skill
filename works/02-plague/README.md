# No.02《黑死病》Pestis Nigra · Firenze 1348

两张，同一种刻法，和 No.01《切尔诺贝利》一样：先刻背景（夜空、河面、雾的横向断线），再把房子、面具、尸骨整块剪影盖上去，最后只在剪影的上沿刻一道断断续续的亮边。物体内部大量留黑，不排匀线，不做受光鼓包。

## FIG. I《面具塔》`plague_tower.py`

鸟嘴医生的面具长成一座钟塔，长喙伸进从城里升起的黄绿瘴气，一只巨蚤顺着喙尖往镜片爬；黑家鼠的骨架横跨黑水当桥，运尸车和提灯的小人走在它的脊椎上；鼠疫杆菌像两头发亮的灯笼飘在瘴气里。唯一的焦点：镜片。

![No.02 FIG. I](../../examples/02_plague_s1.png)

## FIG. II《尸岸》`plague_pile.py`

城压在画面顶上，穹顶、乔托钟楼、旧宫的塔，几扇暖窗；阿诺河占中间，一条运尸船；下三分之一是病死的人和枯骨堆成的岸，骷髅、肋骨、裹尸布、耷拉的胳膊一件压一件。唯一的焦点：船头那盏灯和它在水里的倒影。

![No.02 FIG. II](../../examples/02_plague_pile_s1.png)

## 配色
13 寄生生物（底 `#1E191C`，由 `#51434B` 压深）
- `#7A91A0` 冷刻线：夜空、河面、剪影的亮边
- `#9BAA87` 瘴气、杆菌、星
- `#D7B66D` 窗光、杆菌两极、提灯
- `#C98C9A` 焦点：FIG. I 镜片 / FIG. II 船灯
