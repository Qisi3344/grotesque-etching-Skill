# No.01《切尔诺贝利》

配色 17「标本编号」：底 `#1E1B19`（墨迹褐 `#514943` 压深）· `#6E8FB1` 档案蓝 · `#A1AA92` 记录灰绿 · `#E4D17B` 标签黄 · `#CF6B54` 编号朱红

1986 年 4 月 26 日凌晨，4 号反应堆爆炸。那天夜里，普里皮亚季有人走到铁路桥上，看远处的反应堆发光。

- 夜空：横向断续细刻线，越往下越密，顶上留黑；零星几颗腐蚀出的星
- 烟：1500 条沿噪声旋度场走的流线，从裂口往上翻卷、被风推向右上；中间一束竖向光柱
- 城：随机生成的板楼长出尖塔、穹顶、烟囱，楼间横着高空拱桥；窗光越靠近反应堆越少（人走了）
- 摩天轮：普里皮亚季那座据说从没正式开放过的摩天轮，只剩刻线
- 反应堆：像一座长尖塔的教堂，心口裂开，黄色密排线里一团朱红，光溅到墙上
- 前景：铁路桥栏杆上一排小小的人影，有人抬手指着光；桥下河面碎着黄红倒影
